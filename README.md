# Computer Networks Project - Phase 1

## Project Overview
This is Phase 1 of our Computer Networks course project. Our goal is to design a network for a university with two locations: Main Campus (WAN 1) and Branch Campus (WAN 2). 

In this phase, we set up our team workflow using Google Docs for writing the report and GitHub for saving our project files. We also planned the IP addresses and basic layout for Cisco Packet Tracer.
